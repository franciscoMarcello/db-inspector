O que é

Agentes de IA de qualquer fornecedor (Claude, ChatGPT, Gemini, Copilot ou um script próprio) podem consultar o banco em modo somente leitura e montar relatórios. Tudo o que a IA cria ou altera vira rascunho: nada entra em uso até uma pessoa revisar e publicar.

Como conectar um agente

  1. Abra Tokens para IA e gere um token com um nome que identifique o agente e uma validade em dias.
  2. Copie o token e o comando do modo de conexão que o agente usa (MCP, ChatGPT/OpenAPI ou REST) e cole no agente. O token só aparece uma vez.
  3. Se o agente trabalha dentro de um projeto, use Instruções para IA para baixar o pacote com as regras e coloque os arquivos no projeto.
Abrir Tokens para IA

Onde ver os rascunhos

Na árvore de relatórios, o que a IA criou e nunca foi publicado mostra o selo Rascunho. Um relatório já publicado com alteração esperando revisão mostra Rascunho vN pendente. Selecione o relatório e clique em Versões para ver o conteúdo de cada versão. Cada gravação da IA gera uma versão nova: a anterior vira Rascunho anterior (fica no histórico) e só existe um rascunho aberto por relatório.

Como publicar

Em Versões, selecione o rascunho, confira o SQL, use Comparar com a publicada e rode a Prévia. Se estiver certo, clique em Publicar (a nota é opcional). Se o rascunho foi feito sobre uma versão antiga, a tela avisa. Descartar apaga o rascunho; se o relatório nunca foi publicado, ele é removido. Restaurar volta uma versão antiga criando uma nova versão publicada. Usar como rascunho retoma uma versão antiga (ou um rascunho anterior) como novo rascunho, sem publicar nada; o rascunho aberto, se houver, vira histórico.

O que são os "Pedidos da IA"

Consultas acima do limite de linhas ou de custo não rodam direto: a IA registra um pedido com o SQL e o motivo. Os pendentes aparecem no botão Pedidos da IA (N). Aprovar libera aquele SQL para aquele token, com o número de linhas e o tempo de validade que você escolher; Negar recusa, com uma nota opcional para a IA.

O que a IA não pode fazer

  • Publicar versões de relatório.
  • Excluir relatórios.
  • Restaurar versões antigas.
  • Gerenciar tokens (criar, listar ou revogar).
  • Aprovar os próprios pedidos de liberação.
  • Enviar e-mail.

Tokens expiram

Todo token tem validade (padrão de 30 dias, máximo de 90). Depois disso o agente perde o acesso e é preciso gerar outro. Revogue na hora qualquer token que não for mais usado ou que possa ter vazado.
